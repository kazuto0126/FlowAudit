# 作品介紹影片腳本（3 分鐘以內）

官網規定：介紹影片**不得超過 3 分鐘**、**不得出現姓名及學校名稱**。繳交與播放方式請向主辦單位確認。
旁白約 700 字，以正常語速約 2 分 45 秒，保留一點緩衝。

## 製作提醒

- **錄影**：瀏覽器按 F11 全螢幕、縮放 125%，解析度 1920×1080。可用 Windows 內建的 Xbox Game Bar（Win＋Alt＋R）或免費的 OBS Studio。
- **匿名**：畫面不能出現姓名、學校、電腦使用者名稱、瀏覽器帳號頭像、GitHub 帳號；片頭片尾不要放成員名單。錄影前關掉通知與書籤列。
- **旁白**：組員錄音即可（不要自我介紹），或用文字轉語音。現場可能很吵，一定要加字幕。
- **剪輯**：Windows 內建的 Clipchamp 就夠用；背景音樂用可免費商用的音樂，並保持小聲。
- **數字**：旁白與字幕的數字都要和報告書一致；「可攔阻金額」要說是仿真情境下的上限。
- **輸出**：MP4（H.264）、1080p，剪完確認長度不超過 3:00。
